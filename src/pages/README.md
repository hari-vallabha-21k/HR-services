# Pages

This directory contains page components for your application routes.

## Structure

Each page should be a component that represents a full page view (e.g., `HomePage.tsx`, `DashboardPage.tsx`, etc.).

## Example

```tsx
import React from 'react'

export const HomePage: React.FC = () => {
  return (
    <div>
      <h1>Home Page</h1>
      {/* Page content */}
    </div>
  )
}
```
